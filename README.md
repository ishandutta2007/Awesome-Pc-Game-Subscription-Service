# Awesome-Pc-Game-Subscription-Service

## Top PC Game Subscription Service Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Game Libraries, Cloud Gaming & Self-Hosted Streaming Alternatives*  

**Last updated: October 2026**



This repository tracks notable **commercial PC game subscription services** and **open-source projects** that provide access to game libraries, cloud gaming, and self-hosted streaming. These services range from all-you-can-play catalogs to cloud streaming platforms and open-source alternatives for playing your own games remotely.



**Examples** include Xbox Game Pass for PC, EA Play PC, Ubisoft+ Multi-Access, Humble Choice, Prime Gaming, Apple Arcade, Utomik, Viveport Infinity, Shadow PC Gaming, and Boosteroid (the category leaders).



**Open-source emphasis**: PC game subscription is a domain where open-source alternatives focus on **self-hosted cloud gaming** and **library management** rather than competing catalogs. **Sunshine** + **Moonlight** provide the leading open-source game streaming stack. **Cloudy Pad** deploys gaming instances on your own cloud. **Playnite** and **Heroic Games Launcher** unify owned libraries across stores. **GameVault** offers a self-hosted game library server. This section is heavily expanded.

## Open-Source GitHub Projects



### Self-Hosted Game Streaming



- **[Sunshine](https://github.com/LizardByte/Sunshine)**  

  **The leading open-source game streaming host**, GPL-3.0 licensed with **15,000+ GitHub stars** . **Self-hosted alternative to NVIDIA GameStream** — stream your PC games to any device . **Supports NVIDIA, AMD, and Intel GPUs** with **hardware-accelerated encoding** (NVENC, AMF, QuickSync) . **Low-latency streaming** with H.264, HEVC, and AV1 codecs . **The de facto open-source GeForce Now alternative for your own hardware** . **Best for streaming your own games to any device** .



- **[Moonlight](https://github.com/moonlight-stream/moonlight-qt)**  

  **Open-source game streaming client**, GPL-3.0 licensed with **10,000+ GitHub stars** . **Client for Sunshine and NVIDIA GameStream** — stream games to Windows, macOS, Linux, Android, iOS, and Raspberry Pi . **4K HDR streaming** with low latency . **The standard open-source streaming client** . **Best paired with Sunshine** .



- **[Cloudy Pad](https://github.com/PierreBeucher/cloudypad)**  

  **Free, open-source alternative to GeForce Now and Blacknut**, Apache-2.0 licensed . **Deploy your own gaming instance on AWS, Azure, GCP, Scaleway, Paperspace, or any SSH server** . **Play Steam, Epic, GOG, and Lutris games** without a powerful gaming machine . **Pay by the hour** — ~$15/month for 30 hours using spot instances . **Deploys Sunshine with Moonlight client support automatically** . **The best open-source cloud gaming deployment tool** . **Best for cost-effective cloud gaming on your own infrastructure** .



- **[CloudMorph](https://github.com/giongto35/cloud-morph)**  

  **Decentralized, self-hosted cloud gaming on web browser**, MIT licensed . **Runs Windows games on remote server, streams to browser** — no installation, no console, no plugins . **P2P mesh networking** for providers and consumers . **The best browser-based self-hosted game streaming** . **Best for browser-based cloud gaming** .



- **[Wolf](https://github.com/games-on-whales/wolf)**  

  **Streaming server for Moonlight clients**, MIT licensed . **Runs Windows games in containers on Linux** . **The easiest way to stream Windows games from a Linux server** . **Best for Linux-based game streaming hosts** .



### Self-Hosted Game Library Management



- **[GameVault](https://github.com/Phalcode/gamevault-backend)**  

  **Self-hosted game library server**, AGPL-3.0 licensed with **3,000+ GitHub stars** . **Organize and stream your own game library** — similar to Plex for games . **Supports Windows, Linux, and emulators** . **The best open-source game library server** . **Best for managing your own game collection** .



- **[Playnite](https://github.com/JosefNemec/Playnite)**  

  **The leading open-source game library manager**, MIT licensed with **15,000+ GitHub stars** . **Unifies Steam, Epic, GOG, EA, Ubisoft, Battle.net, Amazon, Xbox, and emulators** into one interface . **Fullscreen mode with controller support** for TV/couch gaming . **The de facto open-source library unification tool** . **Best for managing owned games across stores** .



- **[Heroic Games Launcher](https://github.com/Heroic-Games-Launcher/HeroicGamesLauncher)**  

  **Free, open-source launcher for Epic, GOG, and Amazon Games**, GPL-3.0 licensed with **10,000+ GitHub stars** . **Cross-platform** (Windows, macOS, Linux — including Steam Deck) . **The de facto open-source alternative for non-Steam games on Linux** . **Best for Linux and Steam Deck users** .



- **[Lutris](https://github.com/lutris/lutris)**  

  **Open-source game manager for Linux**, GPL-3.0 licensed with **8,000+ GitHub stars** . **Unified interface for Steam, GOG, Epic, emulators, and native Linux games** . **The most comprehensive Linux gaming manager** . **Best for Linux gamers** .

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Game subscription services are commercial offerings with evolving catalogs. **Games may leave the service at any time** — check current availability before subscribing .

- **Self-hosted cloud gaming requires cloud infrastructure costs** — Cloudy Pad estimates ~$15/month for 30 hours using spot instances, but costs vary by provider and region .

- **Streaming requires stable broadband** — low latency and high bandwidth are essential for playable experience. 4K streaming requires 50+ Mbps .

- **Open-source alternatives do not provide game catalogs** — you must own or legally acquire games. They provide the infrastructure to play games you already own .

- The open-source ecosystem provides strong self-hosted streaming, library management, and cloud deployment foundations, but **curated catalogs, day-one releases, and publisher deals** remain fundamentally commercial offerings.
